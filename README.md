# ⚡ Digital Electronics & RTL Synthesis (Verilog)

This repository contains Verilog HDL lab assignments and hardware logic designs completed for the Digital Electronics Design coursework at Politecnico di Torino.

### 🎯 Core Focus
- **Hardware Description:** Verilog HDL
- **Design Level:** Register-Transfer Level (RTL)
- **Circuit Types:** Combinational and Sequential Logic

### 📂 Lab Contents
- **Combinational Logic:** Implementation and simulation of multiplexers, decoders, and arithmetic logic units (ALUs).
- **Sequential Logic:** Design of flip-flops, shift registers, and counters.
- **Finite State Machines (FSMs):** Custom state machine design for sequence detection and control path routing.
- **Testbenches:** Simulation environments built to verify hardware functionality and timing constraints.

### 🚀 Usage
These modules are designed to be simulated using standard Verilog simulation tools (e.g., ModelSim, Vivado, or Icarus Verilog).
